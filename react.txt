* Javascript library used to build ui
* Single page application (SPA) [Only one HTML paga is recieved and all the pages are recieved at once, so it might load the html once, but never reloads inside courtesy of everything being downloaded already]
* Multi Page Application: Client sends request and recieves a HTML page as response
* React uses component based architecture: re use components anywhere

XSS --> Cross Site Scripting

Created using cross edge scripting

1. Stored XSS --> Script and store in database
2. Reflected XSS
3. DOM XSS

Why needed: While handing out forms, hackers may use it as a gateway to inject malicious contents and to avoid that we use XSS, which is available in frameworks and react which is NOT available in HTML
